persona CLI: command surface

install / activate / remove support interactive target selection and --agent flags. MVP only exposes Claude Code.

Command responsibilities
persona install <role>
choose target agent interactively
or pass --agent claude-code
write output style only
persona activate <role>
choose target agent interactively
or pass --agent claude-code
update outputStyle setting
persona remove <role>
remove package by default
optionally remove agent installs
never delete unrelated config
Agent registry
canonical id: claude-code
alias: claude
future: codex
Non-interactive mode
--agent claude-code
--yes for defaults
clear errors when target unsupported
