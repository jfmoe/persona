     复用 issue #3 已建的 validator/renderer(add 复用 validator;install 复用 renderer 产出 Output Style)。

     都遵守纪律——先写一个会失败的测试(red)、最小实现让它通过(green)、再重构(refactor),
     每个验收标准至少对应一个测试。测试按 PRD Testing Decisions:
     CLI 边界集成测试为主轴,纯逻辑用单元测试补充。
   - 术语严格遵循 CONTEXT.md glossary;遵守 ADR-0001(面具只作用于主会话表达层)、

     最终返回 PR 编号/分支名和一句话变更摘要。
3. subagent 返回后,你(主会话)亲自 review:

   - 逐条核对该 issue 的验收标准是否真的满足;核对术语与 ADR 合规。
